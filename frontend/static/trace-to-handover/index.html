Trace-to-Handover

A Forge app for Jira and Confluence that answers the question every fixed-scope project faces at handover: was everything in the contract built and accepted, and nothing else billed?

What it does

  • Reads the requirement baseline (Terms of Reference, SRS, statement of work) from a Confluence page.
  • Traces each requirement to Jira work items and UAT evidence, and suggests matches for untraced requirements.
  • Flags work items that trace to no requirement (scope creep) and records baseline changes over time.
  • Generates an acceptance report (handover document with sign-off block) in Confluence.
  • Includes a Rovo agent, Handover Auditor, that answers "are we ready for handover?" with evidence.

Getting started

  1. Install the app with the installation link (Jira is required; connect Confluence when prompted).
  2. Open any Jira project and select the Trace-to-Handover tab.
  3. Click Load demo data into this project, or search for your own TOR/SRS page and import it.
  4. Link suggested work items, review out-of-scope work, then click Generate acceptance report.
  5. Open Rovo chat, choose Handover Auditor and ask "Are we ready for handover?"
